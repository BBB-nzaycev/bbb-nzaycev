# My Awesome App 🚀

Современное React приложение для тестирования git истории и демонстрации возможностей.

## ✨ Возможности

- **Интерактивный счетчик** - нажимайте кнопку и смотрите, как растет число
- **Динамическое приветствие** - показывайте/скрывайте приветственный блок
- **Современный UI** - красивые градиенты и анимации
- **Адаптивный дизайн** - работает на всех устройствах

## 🛠 Технологии

- React 19.1.1
- CSS3 с современными возможностями
- Hooks (useState)
- Компонентная архитектура

## 🚀 Запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm start

# Сборка для продакшена
npm run build

# Запуск тестов
npm test
```

## 📁 Структура проекта

```
src/
├── App.js          # Главный компонент
├── App.css         # Стили приложения
├── Welcome.js      # Компонент приветствия
├── config.js       # Конфигурация приложения
├── index.js        # Точка входа
└── index.css       # Глобальные стили
```
